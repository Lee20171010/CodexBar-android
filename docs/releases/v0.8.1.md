# CodexBar for Android v0.8.1

This stable hotfix repairs the Connections crash introduced in v0.8.0. It is not a beta.

## Connections opens normally in release builds

- Fixes the immediate `NullPointerException` that occurred when opening the Connections tab in an optimized release APK.
- Preserves the Google Code Scanner and ML Kit classes required at runtime when AGP 9 runs R8 in full mode.
- Creates the Claude QR scanner only after the user taps **Scan pairing QR**, so opening Connections never depends on scanner initialization.
- Converts synchronous scanner initialization failures into the existing in-app failure state instead of terminating the app.
- Extends the signed-release emulator test to open `codexbar://connections` and reject any process exit or crash before publication.

No credential format or local database migration is included. Existing encrypted connections, usage history, widget configuration, and preferences remain compatible with v0.8.0.

## Install or update

1. Download `app-release.apk` from the assets below.
2. Optionally compare its SHA-256 digest with `SHA256SUMS`.
3. Install it directly over v0.8.0. Do not uninstall first, because uninstalling removes local credentials and preferences.
4. The companion archives are republished as v0.8.1 for version consistency; existing v0.8.0 companion installations remain protocol-compatible.

## Verification

- The original v0.8.0 failure was reproduced from the published APK on an Android 16 emulator.
- The obfuscated stack was matched to `com.google.android.gms.internal.mlkit_code_scanner.zzny` using the deterministic release mapping.
- The fixed, R8-minified release APK remained alive with an empty app crash buffer after opening Connections.
- Unit tests, strict dependency verification, lint, signed release startup, Connections navigation, signer validation, SBOM generation, checksums, and artifact attestation are enforced before publication.
